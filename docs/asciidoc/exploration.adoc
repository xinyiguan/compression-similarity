=== Phase 2: [With context]
[latexmath]

```
D(x,y,ctx) 
    C([x,y] + ctx) - min(C([x]+ctx),C([y]+ctx)) 
=   -------------------------------------------
        max(C([x]),C([y]))
```

this is analogous to partial derivatives at `ctx`

`(f(a+[dx,dy]) - min (f(a+dx),f(a+dy))) / max(f(dx),f(dy))`
