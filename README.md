# Compression-based model of harmonic similarity

This repository contains code and data from the publication:


> X. Guan, E. Hall, Z. Ren, M. Borsodi-Benson, C. Pelofi and M. Rohrmeier, "Comparing Compression-Based Models of Similarity in Jazz Harmonic Progressions", in <em>Proc. of the 27th Int. Society for Music Information Retrieval Conf.</em>, Abu Dhabi, UAE, 2026.
